# placeholders/

Place future animal photos and other content images here (e.g. `dog-1.jpg`, `cat-1.jpg`).

Until real photos exist, entity cards (see `.entity-card-media` in [css/components.css](../../css/components.css))
render a soft gradient tile with a Bootstrap Icon as a placeholder. Animal imagery should be used
selectively on animal-related pages only, per the project's visual style guidelines.
