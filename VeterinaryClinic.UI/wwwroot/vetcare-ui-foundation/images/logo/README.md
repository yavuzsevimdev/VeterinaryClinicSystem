# logo/

Place the real VetCare clinic logo files here (e.g. `logo.svg`, `logo-mark.svg`, `logo-white.svg`).

Until a real logo exists, the sidebar brand mark (`.sidebar-brand-mark` in [index.html](../../index.html))
uses a Bootstrap Icon (`bi-heart-pulse-fill`) inside a gradient tile as a placeholder — swap that
`<i>` element for an `<img>` pointing at a file in this folder when the logo is ready.
